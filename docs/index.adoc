== Overview

AsciiDoctest parses Python code blocks directly from AsciiDoc documents and Python docstrings using AST-based parsing powered by link:https://github.com/webmaven/asciidoctrine[asciidoctrine] and link:https://github.com/webmaven/asciidocstring[asciidocstring].

* **Verifiable Code Examples**: Keep tutorials, user guides, and docstrings continuously verified.
* **Symmetric Execution Models**: Predictable state handling (`test`, `shared`, and `shared, test`) across interactive REPL sessions and non-interactive scripts.
* **Seamless Integration**: Built-in support for link:https://docs.pytest.org/[pytest] automatic test collection and standard library link:https://docs.python.org/3/library/unittest.html[unittest] suite adapters.
