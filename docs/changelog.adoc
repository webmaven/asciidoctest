This document catalogs release history and updates for `asciidoctest`.

== link:https://pypi.org/project/asciidoctest/0.2.0a3/[0.2.0a3] - 2026-08-22

=== Added
* **Section Scoping, Named Contexts & Reset Markers (Issue #2)**:
  - AST section boundary scoping resetting shared states across `==` section headings.
  - Named context scopes (`shared="name"`) for isolated persistent timelines.
  - Explicit reset markers (`[source,python,reset]`).
* **Direct Doctest Extraction API (Issue #3)**:
  - Standalone `extract_and_run_docstring_tests` function for Python files, directories, and loaded modules.
  - AST-based static docstring discovery `find_docstrings_in_py_file`.

=== Fixed
* **Tolerant Illustrative Includes (Issue #1)**:
  - Default `preprocess_directives=False` during doctest extraction.

=== Changed
* **Upgraded Dependencies**:
  - Upgraded `asciidoctrine` to `>=0.2.0a2` and `asciidocstring` to `>=0.1.0a7`.

== link:https://pypi.org/project/asciidoctest/0.2.0a2/[0.2.0a2] - 2026-07-31

=== Added
* **Security Policy & Documentation**:
  - Added `SECURITY.adoc` and dedicated Sphinx `security.adoc` page detailing execution safety rules and vulnerability reporting processes.

=== Changed
* **Upgraded Dependencies**:
  - Upgraded `asciidoctrine` requirement to `>=0.1.0a11` to support configurable custom URI schemes, bare URL and email autolink features, list continuations, and Post-AST syntax checks.
  - Upgraded `asciidocstring` requirement to `>=0.1.0a6`.
* **Documentation & Theme**:
  - Published multi-page documentation website using `sphinx_rtd_theme` customized with AsciiDoctrine's forest-green dark theme.

== link:https://pypi.org/project/asciidoctest/0.2.0a1/[0.2.0a1] - 2026-07-17

=== Added
* **Unified Symmetric Namespace and State Model**:
  - Established symmetric execution rules for REPL and script blocks (`test`, `shared`, `shared, test`).
* **Intelligent `eager` Mode Safety Guard**:
  - Bypasses `eager` fallback when explicit markers exist.

== link:https://pypi.org/project/asciidoctest/0.1.0a4/[0.1.0a4] - 2026-07-16

=== Added
* **Traverser Safety Guard**: `SafeTestBlockExtractorVisitor`.
* **Pytest Discovery Constraints**: Restricted discovery to `tests/` and `README.adoc`.
